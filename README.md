# Международный университет фитнес-индустрии

Адаптивный одностраничный сайт для Международного университета фитнес-индустрии (МУФИ). Лендинг знакомит посетителя с образовательными программами и семинарами, документами об образовании, командой и способами связи, а также позволяет оставить заявку.

## Возможности

- адаптивная вёрстка для мобильных устройств, планшетов и десктопов;
- навигация по якорям и мобильное меню;
- интерактивные списки фитнес-курсов и семинаров;
- слайдеры документов, команды и отзывов;
- раскрывающийся FAQ;
- формы обратного звонка и заявки на обучение;
- маска российского номера телефона и клиентская индикация заполнения полей;
- модальные окна с подтверждением отправки;
- карта Яндекса и контактные данные.

## Стек

- HTML5;
- CSS3 с медиазапросами (`768px` и `1024px`);
- JavaScript (ES6, без сборщика);
- [Petite Vue](https://github.com/vuejs/petite-vue) — декларативная интерактивность прямо в разметке;
- [Swiper 9](https://swiperjs.com/) — слайдеры;
- [SimpleBar](https://github.com/Grsmto/simplebar) — кастомные полосы прокрутки;
- [Maska](https://github.com/beholdr/maska) — маска телефонного номера.

Библиотеки подключаются по CDN, поэтому для полной работы страницы нужен доступ к интернету.

## Структура проекта

```text
.
├── index.html            # Разметка страницы, данные блоков и обработчики Petite Vue
├── main.css              # Стили, адаптивность и визуальные состояния
├── main.js               # Инициализация слайдеров, SimpleBar и Maska
└── resources/
    ├── fonts/            # Локальные варианты Roboto
    ├── icons/            # SVG-иконки и плейсхолдер отзыва
    └── images/           # Изображения для секций и карточек
```

## Запуск локально

Сайт не требует установки пакетов или этапа сборки. Запустите любой статический HTTP-сервер из корня проекта, например:

```powershell
py -m http.server 8080
```

После этого откройте [http://localhost:8080](http://localhost:8080) в браузере.

> Не рекомендуется открывать `index.html` напрямую через `file://`: изображения в разметке используют абсолютные пути вида `/resources/...`, рассчитанные на HTTP-сервер.

## Интерактивность

Состояние интерфейса хранится в `v-scope` внутри [index.html](index.html): открытие мобильного меню и FAQ, переключение карточек, выбранное направление и значения полей форм. В [main.js](main.js) создаются:

- мобильный слайдер документов и десктопная прокрутка списка курсов;
- слайдер команды;
- слайдер отзывов;
- маска `+7(###)-###-##-##` для телефонных полей.

## Текущие ограничения

- Отправка форм не интегрирована с сервером: обработчик отменяет отправку и показывает диалог об успехе. Для приёма заявок нужен API или обработчик формы.
- В контенте используются демонстрационные данные: часть карточек, отзывов и ссылок в соцсетях требует наполнения перед публикацией.
- Заголовок страницы сейчас имеет значение `Document`; перед релизом его стоит заменить на осмысленный SEO-заголовок.
- Версии части CDN-зависимостей заданы как `latest`, поэтому для воспроизводимой публикации лучше закрепить конкретные версии.

## Проверка перед публикацией

1. Проверьте сайт на ширинах до `767px`, от `768px` и от `1024px`.
2. Убедитесь, что CDN-скрипты загрузились и работают слайдеры, маски и раскрывающиеся блоки.
3. Замените тестовые данные, ссылки `#`, телефон на первом экране и текстовые заглушки актуальной информацией.
4. Подключите безопасную серверную обработку форм и политику конфиденциальности.
